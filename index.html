RTC Exporter

Version 3.0.0 · Eclipse update site

Export selected IBM Engineering Workflow Management Pending Changes or loaded change-set history as JSON, Markdown, and Git-style unified patches.

Install

In Eclipse, open Help → Install New Software…, add this repository, then select RTC Exporter:

https://ares16x16.github.io/rtc-exporter/p2/

Version 3 features

  • Select change sets, unresolved changes, or individual files before exporting.
  • Export all loaded History entries or particular completed change sets and files.
  • Generate bounded text diffs while identifying binary and oversized changes safely.

Requirements

Install and configure the official IBM Engineering Workflow Management Eclipse client first. RTC Exporter requires a Java 17-compatible Eclipse runtime.
